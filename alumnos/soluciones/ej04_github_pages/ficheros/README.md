# Panadería de Pilar Azcona · Puente la Reina

Página web estática de presentación de la panadería de Pilar Azcona, publicada gratis con **GitHub Pages**.

## Contenido

- `index.html` · la web (HTML + CSS puro, sin dependencias)
- `PASOS.md` · guía numerada para crear el repositorio en GitHub, activar Pages y publicar
- `.gitignore` · archivos locales que no se publican

## Publicación

El repositorio se publica desde la rama `main` con GitHub Pages: la URL pública quedará como
`https://<usuario>.github.io/<nombre-repo>/`. Los pasos exactos están en [`PASOS.md`](PASOS.md).

## Créditos

Contenido elaborado en el taller de IA de TCSA (junio 2026).
