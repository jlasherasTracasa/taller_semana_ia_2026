# Página personal de Pilar Azcona

Web personal estática (una sola página, `index.html`) para publicar en
**GitHub Pages**. Sin dependencias: HTML y CSS en un único archivo.

## Contenido

- `index.html` — la página completa (estilos incluidos).
- `PASOS.md` — guía numerada para publicarla en GitHub Pages.

## Publicación rápida

1. Crea un repositorio en GitHub.
2. Sube este contenido (`git push`).
3. Activa GitHub Pages desde *Settings → Pages*.

Los pasos detallados están en [PASOS.md](PASOS.md).
